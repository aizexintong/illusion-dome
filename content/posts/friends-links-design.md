## 独立博客的社交货币

在社交媒体算法主宰的时代，独立博客之间的链接交换是一道独特的风景。它不是 SEO 策略，而是一种社交仪式——"我读了你的博客，觉得不错，希望放在我的页面上。"

幻梦为这个仪式设计了一个体面的展示空间。

## 友链卡片

```yaml
friends:
  friends:
    - name: "示例友链"
      url: "https://example.com"
      avatar: "https://t.alcy.cc/tx"
      description: "这是一个示例友链的描述"
      category: "技术博客"
```

每个友链渲染为一张玻璃态卡片：圆形头像 + 站点名 + 简短描述 + 分类标签 + 访问链接（箭头图标）。

Hover 时头像微微放大，卡片整体上浮。分类标签使用半透明背景，帮助读者判断这个站点的内容类型。

## 申请区域

友链页底部有一个"申请友链"区域：

```yaml
apply:
  title: "申请友链"
  conditions:
    - "内容优质，原创技术文章优先"
    - "定期更新，保持活跃"
    - "无不良内容，健康向上"
    - "已添加本站链接"
  siteInfo:
    name: "爱则心痛 (azxt)"
    url: "https://azxt.org"
    description: "爱则心痛的个人博客"
  contactMethods:
    - icon: "fas fa-envelope"
      label: "发送邮件"
      link: "mailto:admin@azxt.org"
```

区域分为两栏：左侧是申请条件清单（每项带对勾图标），右侧是本站信息和联系方式。

## 设计原则

**平等展示**：不以友链的知名度或流量排序，默认按添加顺序排列。

**完整性**：每张卡片包含头像、名称、描述、分类和直达链接，访客不需要做额外搜索。

**诚实**：申请条件公开透明，邮件和 GitHub Issues 两种联系方式可选。

## 数据驱动

全部友链数据在 `theme.yaml` 中维护。添加新友链只需要插入一个 YAML 对象，页面自动生成卡片。删除同理。
