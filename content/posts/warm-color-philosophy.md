## 代码世界普遍是冷的

打开大多数技术博客和开发者工具，你会发现主色调几乎都是蓝色系：蓝、深蓝、蓝灰。这不是巧合——蓝色长期与"科技"、"理性"、"专业"绑定。

但问题在于：**你每天盯着这些冰冷的色调8小时以上，它们不会让你感到舒适。**

## 暖色调入场

幻梦选择了暖桃色 / 杏色系作为浅色模式的基底。这不是随意的选择。

暖色调在色彩心理学中有三个优势：

### 1. 降低视觉疲劳

蓝色光是高能可见光（HEV 光），长时间暴露会增加眼疲劳。暖色系（偏红/橙）的色温更低，对视网膜的刺激更小。

浅色模式的背景色 `#FDF8F5`——一种极淡的暖粉白色——取代了刺眼的纯白，让长时间阅读更舒适。

### 2. 建立情感连接

冷色调传达的是距离感——银行、医院、企业软件的界面多是蓝色。暖色调传达的是亲近感——咖啡馆、书店、朋友家的客厅。

一个个人博客不需要"专业"到生疏。它应该像一个你愿意待着的房间。

### 3. 与图片兼容

博客中会插入各种图片：截图、照片、图表。暖色调的页面背景比冷色调更容易与这些多样化的视觉内容兼容——它像一个中立的、温暖的画布。

## 渐变作为桥梁

幻梦使用渐变将暖色（桃色）与辅助色（紫色、金色、绿色）连接：

```css
.gradient-text {
  background: linear-gradient(135deg,
    var(--cp4) 0%,   /* 暖桃/purple */
    var(--ca4) 50%,  /* 金色 */
    var(--cg4) 100%  /* 绿色 */
  );
}
```

渐变不是两个颜色的简单过渡——它是幻梦色彩系统的视觉签名。

## 深色模式的暖

即使是深色模式，背景也不是纯黑，而是极深的暖棕色 `#0E0A08`。纯黑的深色模式在暗环境中会让文字周围产生"光晕"，而带暖调的深色背景消除了这种效应。

---

*暖色调是幻梦与大多数技术主题最根本的区别。它不是"更好看"，而是"更让人想留下来"。*
