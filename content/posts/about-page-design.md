## 关于页是博客的第二入口

很多读者访问博客时不会直接看文章。他们会先点到"关于"页面——"这个博主是谁？值不值得关注？"

一个清晰的关于页比 10 篇高质量文章更能建立信任。

## 信息分区

### 个人介绍

```yaml
about:
  intro:
    name: "爱则心痛 (azxt)"
    title: "全栈开发者 · 技术爱好者 · 开源贡献者"
    quote: "代码如诗，技术如画。"
```

头像、姓名、一句话定位、座右铭。这是"名片"区域——读者在这里形成第一印象。

### 数据统计

```
[ 技术文章 ]  [ 技术技能 ]  [ 开发经验 ]  [ 热爱程度 ]
    auto         auto          8+            ∞
```

四个统计数字，前两个用 `"auto"` 自动计算（文章数和技能数），后两个手动填入。数字比文字更有说服力。

### 技术理念

```
✨ 优雅简洁            📚 持续学习
追求代码的简洁...      技术日新月异...

🤝 分享共赢            ❤️ 用户体验
知识因分享而...        技术服务于人...
```

四个理念卡片，在桌面端排列成 2x2 或 4 列网格，每个包含图标 + 标题 + 简短解释。这一区域告诉读者"你关心什么"，比技能列表更能传达价值观。

### 联系方式

```
📧 邮箱：admin@azxt.org
🐙 GitHub：aizexintong
🌐 网站：azxt.org
```

三种联系方法，每种带有可点击的链接。放在页面底部，作为"如果你看到这里还想联系我"的入口。

## 可选的Markdown内容

```yaml
---
title: "关于我"
layout: "about"
---

## 更多关于我的故事
欢迎来到我的个人空间！我是 **爱则心痛**...
```

`layout: "about"` 告诉 Hugo 使用 `about.html` 模板，模板渲染 YAML 数据驱动的上部，然后渲染 `.Content`（Markdown 正文）。两部分可以共存，互相补充。

## 关于页和首页的关于区域

首页底部的"关于"区域是关于页的精简版——一个头像 + 几句介绍 + "了解更多"按钮。两个页面共享同一份数据（`theme.yaml` 中的 `about` 节点），但使用不同的模板 partial。

---

*关于页是博客中最私人的页面。它不是简历，是一封给陌生人的自我介绍信。*
